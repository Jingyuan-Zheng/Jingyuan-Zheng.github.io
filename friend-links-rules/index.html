This page explains the eligibility, submission methods, and maintenance principles for backlinks on this site. Please read the complete rules before applying.

Last updated: July 25, 2026.

Basic Requirements

  • The website should be an accessible personal site or independent blog with a clear name and original content that is still being maintained.
  • Backlinks are reciprocal. Add this site to your backlinks page before applying and make sure the link is publicly accessible.
  • It should use HTTPS and must not contain malicious redirects, scams, phishing, malware, or anything else that could put visitors at risk.
  • Sites centered on illegal material, explicit adult content, hate or harassment, piracy, advertising, copied content, or search-ranking manipulation will not be accepted.
  • Your subject, technology stack, traffic, and publishing schedule do not need to match this site. A genuine, complete, and maintained website is enough.

Information to Submit

Please include:

  1. Website name;
  2. Website URL;
  3. A one-line description;
  4. An avatar or site-icon URL;
  5. The URL of the backlinks page where you added this site;
  6. An English name and description, if available.

If no English name or description is supplied, the English backlinks page will preserve the original wording instead of inventing a translation.

How to Apply

Return to the Links page and submit your request through the embedded backlink application system.

Open the backlink application system

Comments remain open for discussion but are not an application channel. Add this site before applying and include the public backlinks page where the link can be verified. This site will add your link after confirming it. If you have trouble completing or submitting the form, email mr.jingyuan.zheng@gmail.com.

Review and Maintenance

  • Requests are reviewed manually. Meeting these rules does not guarantee acceptance, and there is no fixed response time.
  • After review, I will use the contact details supplied in the application to confirm whether it is accepted or declined. If declined, I will include the reason, so please watch for a response.
  • Names and descriptions normally use the applicant’s supplied wording. If the text is too long for the card, I may ask for a shorter version.
  • A link may be removed if the site remains unavailable, changes ownership, redirects elsewhere, or no longer meets these rules.
  • If the other site removes this site’s link without notice, its link may also be removed here.
  • Use the backlink application system to request an update when your URL, name, description, or avatar changes; email only if you run into a problem.
